Personal Finance Reader

Privacy Policy

Effective date: 12 November 2026 · Project status: prototype

1. Purpose

Personal Finance Reader is a private, non-commercial software project intended for its owner's use with bank accounts owned by that same person. The goal is to allow the owner to review account balances and transaction history through an authorised, read-only banking connection.

2. Information processed

If the application is activated and the owner authorises a banking connection, it may access account identifiers, account balances, transaction amounts, dates, and transaction descriptions strictly for personal financial analysis. This website itself does not request or process banking information.

3. Authentication and consent

Bank authorisation takes place through the bank's and/or authorised connectivity provider's own consent process. The application is not intended to request or store the owner's banking passwords, PINs, or one-time authentication codes. The owner may revoke consent through the appropriate banking or provider channels.

4. Storage and sharing

The intended implementation processes and, where necessary, stores account information locally on devices controlled by the owner. The project does not sell or publish financial data. Banking connectivity necessarily involves the bank and the authorised provider, which operate under their own privacy notices. Any future cloud or AI integration that transmits financial information must be disclosed here before use and authorised by the owner.

5. Security and retention

Banking API credentials and private keys must not be published on this website or committed to a public repository. The owner is responsible for protecting any local credentials and deleting stored data when it is no longer needed. The implementation and data-retention details will be reviewed before production use.

6. This website

These pages are hosted through GitHub Pages. No custom analytics, account registration, or contact forms are included. GitHub may process technical access information under its own policies.

7. Contact and changes

For project contact, see the developer profile at github.com/ponaehalive. Do not post bank information or credentials in public issues. This policy will be updated if actual application data flows differ from the prototype described here.
